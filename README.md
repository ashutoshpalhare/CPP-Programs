# 100 C++ Programming Programs

A structured collection of **100 C++ programming examples** designed to help beginners learn C++ fundamentals, strengthen problem-solving skills, and practice core programming concepts through hands-on coding.

This repository contains individual `.cpp` source files organized by topic, making it easier to learn, practice, revise, and experiment with C++.

## 🎯 About This Repository

Learning a programming language requires more than understanding its syntax. Consistent coding practice helps develop logical thinking, problem-solving abilities, and confidence.

This repository brings together 100 practical C++ programs, starting with basic input/output and gradually moving towards functions, recursion, arrays, pointers, object-oriented programming, and file handling.

**Whether you are a beginner learning C++ or a student revising programming fundamentals, this collection provides a practical starting point.**

## 📚 Topics Covered

The programs are organized into topic-based folders.

| No. | Topic | Description |
|---|---|---|
| 01 | C++ Basics | Output, input, variables, and basic operations |
| 02 | Conditional Statements | `if`, `else`, nested conditions, and `switch` |
| 03 | Loops | `for`, `while`, and `do-while` loops |
| 04 | Number Logic | Prime numbers, factorials, Armstrong numbers, and more |
| 05 | Pattern Programs | Star, number, and character patterns |
| 06 | Arrays & Matrices | Array operations and matrix manipulation |
| 07 | Strings | String operations and character processing |
| 08 | Functions & Recursion | User-defined functions and recursive solutions |
| 09 | Pointers & References | Pointer basics and reference concepts |
| 10 | Object-Oriented Programming | Classes, objects, constructors, and related concepts |
| 11 | STL & Advanced Concepts | Standard Template Library and useful C++ features |
| 12 | File Handling | Reading from and writing to files |

*The collection also includes practical examples such as a basic student management program.*

## ⚙️ Requirements

To compile and execute these programs, you need:

- A C++ compiler (GCC or Clang recommended).
- C++17 or newer.
- A code editor such as Visual Studio Code, Code::Blocks, or any IDE that supports C++.

### Recommended Setup

- **Compiler:** GCC (MinGW on Windows)
- **Language Standard:** C++17
- **Editor:** Visual Studio Code

## 🚀 How to Run a Program

### 1. Clone the Repository

```bash
git clone https://github.com/ashutoshpalhare/CPP-Programs.git
```

### 2. Navigate to the Project

```bash
cd CPP-Programs
```

### 3. Open a Program

Choose any `.cpp` file from the topic folders.

### 4. Compile the Program

Using GCC:

```bash
g++ -std=c++17 program.cpp -o program
```

### 5. Execute the Program

**Windows:**

```bash
program.exe
```

**Linux / macOS:**

```bash
./program
```

Replace `program.cpp` with the actual source filename.

## 💡 Learning Roadmap

For the best learning experience, follow this sequence:

1. Start with basic syntax, variables, and input/output.
2. Understand conditional statements and loops.
3. Practice number-based logic and pattern problems.
4. Learn arrays, matrices, and strings.
5. Understand functions and recursion.
6. Explore pointers and references.
7. Learn object-oriented programming.
8. Practice STL and file handling.
9. Modify existing programs and try solving problems independently.

**Tip:** Don't just copy and execute the programs. Understand the logic, experiment with different inputs, and try implementing each solution yourself.
